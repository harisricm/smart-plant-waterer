# Smart Plant Waterer

## Introduction

The Smart Plant Waterer is an IoT-based irrigation system that monitors soil moisture levels and automatically activates watering when the soil becomes dry.

## Objective

The objective of this project is to automate plant watering and demonstrate the use of sensors and ESP32 in smart agriculture applications.

## Components Used

* ESP32
* Potentiometer (simulated soil moisture sensor)
* LED (simulated water pump indicator)
* Wokwi Simulator

## Working Principle

1. The soil moisture sensor measures the moisture level.
2. ESP32 reads the sensor value.
3. If the soil is dry, the system turns ON the water pump indicator.
4. If the soil is wet, the system turns OFF the water pump indicator.
5. Sensor values are displayed in the Serial Monitor.

## Advantages

* Automated watering
* Saves water
* Reduces manual effort
* Easy to implement

## Applications

* Smart gardening
* Agriculture automation
* Indoor plant monitoring
* Greenhouse systems

## Conclusion

The Smart Plant Waterer demonstrates how IoT can be used to automate irrigation and improve plant care through real-time monitoring and control.
