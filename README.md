## Project Overview

The Smart Plant Waterer is an IoT-based system that monitors soil moisture levels and automatically waters plants when the soil becomes dry.

## Project Scope

This project demonstrates automated plant care using sensors and ESP32 technology. It helps maintain proper soil moisture without manual intervention.

## Objectives

* Monitor soil moisture levels
* Automate plant watering
* Learn sensor integration
* Understand IoT automation concepts
